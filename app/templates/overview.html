The pipeline

One command, python main.py, runs every step below. This app reuses the same code and the saved preprocessor.

  1. Understand

    Types, missing values, duplicates and odd values counted before anything changes.

    {{ "{:,}".format(overview.duplicates) }} duplicate rows found

  2. Clean

    Invalid rows, exact duplicates, missing values and an extreme price, in a fixed order.

    {{ "{:,}".format(overview.raw_rows - overview.clean_rows) }} rows removed

  3. Engineer

    Ten new row-wise features such as price per person and a guest's cancellation history.

    {{ features.engineered | length }} new features

  4. Explore

    Cancellation rates by lead time, season, deposit, segment, country and requests.

    11 figures · interactive charts

  5. Select

    Leakage, redundancy and near-constant checks on training rows only.

    {{ features.dropped | length }} candidates dropped with reasons

  6. Encode & scale

    Split first, then fit log + scaling + one-hot encoding on the training set only.

    {{ overview.n_outputs }} model-ready columns
